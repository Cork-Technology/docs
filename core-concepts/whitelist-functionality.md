# Whitelist Functionality

When configuring Cork markets, an optional whitelist feature is enabled. The feature is market specific and if enabled, restricts the ability to interact with that market to addresses which have been added to a whitelist.\
\
Cork opted to introduce whitelisting functionality as a security precaution, as it meaningfully reduces possible attack surface on whitelisted markets. Furthermore, certain institutional use cases are better implemented with a whitelist. Public markets without a whitelist can be configured, such markets cannot later be whitelisted. \
\
A multisig is responsible for maintaining the market-specific whitelist. If you are a user of Cork and would like to be whitelisted for a given market, please contact the team to be onboarded to the market.
